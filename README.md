# Project Refactor — skill for Codex

`project-refactor` — универсальный скилл для безопасного аудита, очистки и оптимизации программных проектов после многочисленных доработок с ИИ.

## Возможности

- **`quick-cleanup`** — аккуратная очистка недавно изменённого кода.
- **`deep-audit`** — анализ всего проекта с перечнем кандидатов на удаление и планом без автоматических изменений.
- **`release-optimization`** — рефакторинг стабильной версии небольшими проверяемыми этапами.

Скилл учитывает работу с Python, JavaScript/TypeScript, SQL/ETL и смешанными проектами. Поддерживается работа без Git.

### Безопасность

- Сначала определяется фактическая структура проекта и состояние тестов.
- Файлы и зависимости не удаляются без явного согласования конкретных кандидатов.
- Сохраняются пользовательские данные, миграции БД, настройки, публичные интерфейсы и интеграции.
- Изменения проверяются поэтапно; без достаточной проверки поведение программы не объявляется сохранённым.
- Оптимизация производительности проводится по измерениям, а не предположениям.

## Установка в Codex (Windows)

Проще всего открыть Codex в VS Code и передать ему текст из [INSTALL_PROMPT.md](INSTALL_PROMPT.md).

Альтернатива — вручную скопировать **всю** папку `skills/project-refactor` в пользовательский каталог Codex:

`%USERPROFILE%\.agents\skills\project-refactor`

Скопируйте также подпапки `agents`, `assets`, `references` и `scripts`. Если уже существует одноимённый скилл, не перезаписывайте его без проверки различий.

## Использование

```text
Используй $project-refactor в режиме deep-audit. Проверь весь проект и предложи план очистки. Ничего не изменяй.
```

```text
Используй $project-refactor в режиме quick-cleanup для недавно изменённого модуля. Сохрани функциональность и выполни необходимые проверки.
```

```text
Используй $project-refactor в режиме release-optimization. Сначала зафиксируй проверки и предложи этапы оптимизации. Приступай к изменениям только после согласования.
```
