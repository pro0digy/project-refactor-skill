# Промпт для установки в VS Code + Codex

Скопируй в чат Codex следующий текст:

---

Установи пользовательский скилл `project-refactor` для всех моих проектов Codex.

Источник: https://github.com/pro0digy/project-refactor-skill/tree/main/skills/project-refactor

1. Проверь доступность и содержимое репозитория. Прочитай `SKILL.md` и убедись, что вспомогательные файлы не выполняют нежелательных сетевых или изменяющих систему действий.
2. Найди действующий пользовательский каталог скиллов Codex в этой среде. На Windows обычно используется `%USERPROFILE%\.agents\skills`.
3. Если `project-refactor` уже существует, сначала сравни его с источником и запроси разрешение на замену. Не перезаписывай автоматически.
4. Установи всю папку `skills/project-refactor` со всеми вложенными файлами (`SKILL.md`, `agents/`, `assets/`, `references/`, `scripts/`) в пользовательский каталог навыков.
5. Проверь YAML-заголовок: имя должно быть `project-refactor`, а описание должно определять условия вызова. Проверь наличие всех вспомогательных файлов.
6. Если доступен Python, проверь синтаксис и безопасную работу `scripts/project_inventory.py` на специально созданной небольшой тестовой папке. Скрипт должен только выводить отчёт и не менять файлы.
7. Убедись, что скилл доступен для явного вызова `$project-refactor`.

**Ограничения:** не меняй код открытого проекта; не запускай рефакторинг; не удаляй и не перемещай пользовательские файлы; не устанавливай дополнительные библиотеки без необходимости.

В конце сообщи путь установки, перечень установленных файлов и результат проверки.
